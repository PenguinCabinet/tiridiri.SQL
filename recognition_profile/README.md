# この動画の認識プロファイル

`profile.json` の座標系は640×360です。実体の顔と座席位置は元動画の840フレーム、
遺影は120フレーム（主人公のみ3120フレーム）から取得しました。
主人公の単独ポーズは120フレーム、閉眼は1920フレームから追加しています。
0フレームの接写は、冒頭の大きな拡大率でも位置を推定するための基準画像です。
`source_sha256` に元動画のハッシュを保存しています。

実体は基準画像の特徴点を使って毎フレーム位置合わせし、遺影は独立した固定レイヤー
として照合します。プロファイルは正解の時系列を含みません。
元からある `pattern_matches/` の画像を上書きせず、切り出した画像をここに保存しました。

顔が画面外の場合は不在とします。顔のごく小さい切れ端だけを誤検出しないため、
基準の顔領域の25%以上が画面内にあることを要求します。体だけが映る人物を
カウントする用途には、別の身体領域と評価ラベルが必要です。

再生成はリポジトリ直下から `python evaluation/build_profile.py` で行います。
これは `evaluation/baseline_samples.json` の抽出座標と元動画を使います。
別の動画では、基準画像・顔画像・座席座標・冒頭の座標変換を再設定してください。
